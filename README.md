# Prediksi Overbreak

Website interaktif untuk prediksi overbreak peledakan terowongan dengan regresi linear berganda (MRA) dan ANFIS.

- Kalkulator enam parameter (PF, W, A, Drill, ppf, RQD) dengan gambar penampang terowongan
- Rentang parameter untuk overbreak di bawah 10%
- Grafik sensitivitas dan diagram tornado
- Data 45 peledakan, ukuran kecocokan model, dan persamaan regresi

Seluruh perhitungan berjalan di browser. Tidak ada build step: buka `index.html` atau aktifkan GitHub Pages (Settings, Pages, branch `main`, folder `/root`).
